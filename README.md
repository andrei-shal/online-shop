# Online Shop

Полнофункциональный интернет-магазин, разработанный на PHP с использованием MVC-подхода, MySQL и Docker. Проект включает пользовательскую часть, систему управления заказами, корзину покупок, административную панель и ролевую модель доступа.

## О проекте

Online Shop — это веб-приложение электронной коммерции, позволяющее пользователям просматривать каталог товаров, добавлять товары в корзину, оформлять заказы и отслеживать их статус. Для администраторов предусмотрена отдельная панель управления товарами, пользователями и заказами.

Проект разработан с акцентом на безопасность, расширяемость и разделение ответственности между слоями приложения.

## Основные возможности

### Пользовательская часть

* Регистрация и авторизация пользователей
* Безопасное хранение паролей с использованием bcrypt
* Просмотр каталога товаров
* Детальная страница товара
* Поиск и фильтрация товаров
* Корзина покупок
* Оформление заказов
* История заказов пользователя

### Административная панель

* Управление товарами
* Создание и редактирование карточек товаров
* Загрузка изображений товаров
* Управление пользователями
* Изменение ролей пользователей
* Просмотр и обработка заказов
* Контроль статусов заказов

### Система ролей

Поддерживаются следующие уровни доступа:

* USER — обычный пользователь
* MANAGER — менеджер магазина
* ADMIN — администратор
* SUPER — супер-администратор

## Технологии

### Backend

* PHP 8
* PDO
* MySQL

### Infrastructure

* Docker
* Docker Compose

### Storage & Services

* Amazon S3 совместимое хранилище для изображений
* Email-уведомления

### Security

* password_hash()
* password_verify()
* Prepared Statements (защита от SQL Injection)
* Сессионная аутентификация

## Архитектура проекта

Проект построен по принципу разделения ответственности:

```text
app/
├── db/
│   ├── Database.php
│   └── models/
├── services/
│   ├── EmailService.php
│   └── S3Service.php
├── public/
│   ├── api/
│   ├── admin/
│   └── ...
└── init.php
```

### Основные компоненты

* Models — работа с базой данных
* Services — внешние сервисы и бизнес-логика
* API Layer — обработка запросов
* Admin Panel — инструменты управления магазином

## База данных

Основные сущности:

* Users
* Admins
* Products
* Orders
* ProductsInCart
* ProductsInOrder

Связи реализованы через внешние ключи и обеспечивают целостность данных.

## Безопасность

В проекте реализованы следующие меры безопасности:

* Хеширование паролей через bcrypt
* Использование Prepared Statements
* Разделение прав доступа по ролям
* Проверка авторизации для административных действий
* Защита конфиденциальных данных через переменные окружения

## Запуск проекта

### Клонирование репозитория

```bash
git clone https://github.com/andrei-shal/online-shop.git
cd online-shop
```

### Настройка окружения

Создать файл `.env` и указать параметры подключения к базе данных и сервисам.

### Запуск через Docker

```bash
docker compose up --build
```

После запуска приложение будет доступно по адресу:

```text
http://localhost
```
